# CW Session Notes -- Study Hub

CW session-close notes for this project land here -- LOCAL to study-hub, not
the claude-ops `cw-ops` trail. study-hub is a standalone personal project
(out-of-cadence from the greg.io work system), so its session record stays
self-contained in its own repo.

Naming:  YYYY-MM-DD-cw-[slug]-session-close.md
Each note carries a STATUS flag (GREEN / YELLOW / RED) and an OPEN ITEMS
section, per the universal CW session pattern.

These notes are excluded from the public Vercel deploy via .vercelignore.
