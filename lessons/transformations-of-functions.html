Transformations of Functions

Every function on your worksheet is a familiar shape that's been slid, stretched, or flipped. Learn to read those moves straight off the equation — then the graph, vertex, domain and range fall out for free.

The one template

Everything fits this pattern

Take a parent function P(x) — the plainest version of its shape — and dress it up:

f(x) = a·P(x − h) + k

Three knobs. That's the whole unit.

KnobWhat it doesThe catch
a — stretch / flip|a| > 1 stretches taller; |a| < 1 squishes flatter. A negative a flips it upside-down (over the x-axis).a changes steepness & direction, never left/right.
h — left / rightMoves the graph horizontally.Backwards! (x−3) moves right 3; (x+4) moves left 4. The sign lies — flip it.
k — up / downMoves the graph vertically. +k up, −k down.This one is honest — the sign means what it says.
The whole trick: the point that "anchors" the shape (the vertex of a parabola or V, the start point of a square root) simply moves to (h, k). Find (h, k) and you've basically graphed it.

Reading the answers off

Filling in the worksheet blanks

Parent function

Name the plain shape hiding inside:

x²quadratic (parabola)
|x|absolute value (V-shape)
√xsquare root (half-curve)
xlinear (straight line)

Vertex / start point

It's just (h, k) — remembering h flips its sign. Lines don't have a vertex; write "none."

Domain (allowed x's)

Parabola, V, line: every x works → (−∞, ∞).
Square root: you can't root a negative, so x must start at h → [h, ∞).

Range (reachable y's)

Parabola & V & √: they stop at the anchor's height k. If a is positive the graph opens up → [k, ∞). If a is negative it opens down → (−∞, k].
Line: range is all reals.

Intercepts

y-int: plug in x = 0. x-int: set f(x)=0 and solve (or read where the curve crosses the x-axis).

Watch one all the way through

A twin problem, start to finish

This is not one of your eight — it's a stand-in so you can copy the method, not the answer.

g(x) = −2(x − 1)² + 3

  1. Parent: there's an x² inside → quadratic.
  2. Read the knobs: a = −2, h = 1 (the −1 flips to right 1), k = 3.
  3. Transformations: vertical stretch by 2, reflected over the x-axis (a is negative → opens down), right 1, up 3.
  4. Vertex: (h, k) = (1, 3).
  5. Domain: parabola → (−∞, ∞).
  6. Range: opens down from height 3 → (−∞, 3].
  7. y-int: x=0 → −2(0−1)²+3 = −2(1)+3 = 1.
  8. Graph: plot the vertex (1,3), then the stretch factor tells you the next points: from the vertex go right 1 / down 2, right 2 / down 8 (that's a·1² and a·2²). Mirror on the left.
One of each other family (tap)

Absolute value — g(x) = |x + 2| − 1: parent |x|; h = −2 (left 2), k = −1 (down 1); vertex (−2, −1); domain all reals; a is positive so V opens up → range [−1, ∞).

Square root — g(x) = √(x − 2) + 1: parent √x; h = 2 (right 2), k = 1 (up 1); start point (2, 1); domain [2, ∞) (can't root a negative); range [1, ∞).

Line — g(x) = 2x − 5: parent x; slope 2, y-int −5; no vertex; domain and range both all reals.
