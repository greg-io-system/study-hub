1 · Three ways to solve ax² + bx + c = 0

All three methods find the same thing: the x-values that make the quadratic equal zero (the x-intercepts, if they're real). Your review sheet asks for a specific method on each problem, so know all three.

Factoring (problem 1 type)

When a = 1: find two numbers that multiply to c and add to b.

Twin: x² + 3x − 28 = 0. Multiply to −28, add to +3: +7 and −4.
(x + 7)(x − 4) = 0 → set each factor to zero → x = −7 or x = 4.

When a isn't 1 (the "ac method"): multiply a·c, find two numbers that multiply to ac and add to b, split the middle term, then group.

Twin: 6x² − x − 2 = 0.  ac = 6·(−2) = −12. Multiply to −12, add to −1: −4 and +3.
Split: 6x² + 3x − 4x − 2 = 0
Group: 3x(2x + 1) − 2(2x + 1) = 0 → (3x − 2)(2x + 1) = 0
So x = 2/3 or x = −1/2.

If Mrs. Howard showed a different way in class, use the one in your notes; the answers come out the same.

Trap: the equation must equal zero before you factor. And check your factors by multiplying them back out.

Completing the square (problem 2 type)

  1. Move c to the other side.
  2. Take half of b, square it, and add it to both sides.
  3. The left side is now a perfect square: (x + b/2)².
  4. Square-root both sides (±!), then solve.
Twin: x² + 6x + 5 = 0
x² + 6x = −5 → half of 6 is 3, 3² = 9 → x² + 6x + 9 = −5 + 9
(x + 3)² = 4 → x + 3 = ±2 → x = −1 or x = −5.
Twin where the answer is complex: x² + 6x + 13 = 0
x² + 6x + 9 = −13 + 9 → (x + 3)² = −4
x + 3 = ±√−4 = ±2i → x = −3 ± 2i.
A negative under the square root means no x-intercepts: the answers are complex numbers. That's the link between this unit's two halves (the review sheet's subtitle: "Understanding Complex Numbers Through Quadratics").

The quadratic formula (problem 3 type)

x = ( −b ± √(b² − 4ac) ) / 2a

Twin: 3x² − 5x − 1 = 0. a = 3, b = −5, c = −1.
b² − 4ac = 25 − 4(3)(−1) = 25 + 12 = 37
x = (5 ± √37) / 6. √37 ≈ 6.0828
x ≈ 11.0828/6 ≈ 1.85  or  x ≈ −1.0828/6 ≈ −0.18
Twin: x² + 4x − 9 = 0. b² − 4ac = 16 + 36 = 52.
x = (−4 ± √52) / 2, √52 ≈ 7.2111 → x ≈ 1.61 or x ≈ −5.61.
Traps: −b flips the sign of b (here b = −5, so −b = +5). With a negative c, −4ac turns positive. Divide the whole top by 2a, not just the square root. Round only at the end.

2 · Graphing & the three forms (problems 4–5 + the Converting Forms WS)

FormLooks likeWhat it shows you right away
Standardy = ax² + bx + cThe y-intercept is c. Axis of symmetry: x = −b / 2a
Intercept (factored)y = a(x − p)(x − q)The x-intercepts are p and q (flip the signs!). The axis is halfway between them
Vertexy = a(x − h)² + kThe vertex is (h, k) (flip the sign of h). The axis is x = h

In every form, a is the same number: if a is positive the parabola opens up (vertex = lowest point); if negative it opens down (vertex = highest point).

Starting from standard form

Twin: f(x) = x² − 2x − 8
y-intercept: c = −8 → (0, −8)
Axis: x = −(−2)/(2·1) = 1
Vertex: plug in x = 1: 1 − 2 − 8 = −9 → (1, −9)
x-intercepts: factor: multiply to −8, add to −2 → −4, +2 → (4, 0) and (−2, 0)
Factored form: (x − 4)(x + 2)
Vertex form: (x − 1)² − 9

Starting from intercept form

Twin: f(x) = (x + 2)(x + 6)
x-intercepts: flip the signs → (−2, 0) and (−6, 0)
Axis: halfway: (−2 + −6)/2 = −4
Vertex: f(−4) = (−2)(2) = −4 → (−4, −4)
y-intercept: f(0) = 2·6 = 12 → (0, 12)
Standard form: FOIL → x² + 8x + 12
Vertex form: (x + 4)² − 4

Converting: the moves

  • Vertex or intercept → standard: multiply it out. Twin: y = 2(x + 1)² − 8 = 2(x² + 2x + 1) − 8 = 2x² + 4x − 6. And y = 3(x − 2)(x + 4) = 3(x² + 2x − 8) = 3x² + 6x − 24.
  • Standard → intercept: factor (take out a first if a isn't 1). Twin: 2x² + 4x − 6 = 2(x² + 2x − 3) = 2(x + 3)(x − 1).
  • Standard → vertex: find the vertex (h = −b/2a, then k = f(h)) and write a(x − h)² + k with the same a.
  • From a graph: read the vertex for vertex form and the x-intercepts for intercept form; find a by plugging in one more point (the y-intercept is easiest). Then multiply out for standard form.
Trap: when you multiply out, keep a outside until the very end, then multiply it through every term: 2(x² + 2x + 1) − 8, not (2x + 2)² − 8.

3 · Thrown-object word problems (problems 6–7)

In y = −16x² + bx + c, y is the height and x is the time in seconds. Each question is one of the graph features in disguise:

The question asksIt really meansHow
Initial height (where it was thrown from)?The y-intercept (x = 0)It's c
Maximum height?The vertex's y-valuex = −b/2a, then plug that x in
When does it hit the ground / water?The positive x-intercept (y = 0)Set y = 0; factor or use the formula; keep the positive answer
When is it at height H?Solve y = HSubtract H to get = 0, then solve. Often two answers: once going up, once coming down

"Don't be afraid to make a sketch" (her tip on the sheet): a quick hump with the start height, the top and the landing point keeps the answers straight.

Twin 1: a ball is thrown from a roof: y = −16x² + 48x + 64.
Initial height: 64 ft.
Max: x = −48/(2·−16) = 1.5 s; y = −16(2.25) + 48(1.5) + 64 = −36 + 72 + 64 = 100 ft.
Hits the ground: −16x² + 48x + 64 = 0 → divide by −16: x² − 3x − 4 = 0 → (x − 4)(x + 1) = 0 → 4 s (−1 makes no sense for time).
When at 96 ft? −16x² + 48x + 64 = 96 → −16x² + 48x − 32 = 0 → x² − 3x + 2 = 0 → 1 s and 2 s (up, then down).
Twin 2 (needs the formula and rounding): y = −16x² + 96x + 40.
Initial height: 40 ft.  Max: x = 3 s, y = −144 + 288 + 40 = 184 ft.
Hits the ground: x = (−96 ± √(96² − 4(−16)(40))) / (2·−16) = (−96 ± √11776) / −32. √11776 ≈ 108.52 → x ≈ 6.39 s (the other root, ≈ −0.39, is before the throw).
When at 100 ft? −16x² + 96x − 60 = 0 → x ≈ 0.71 s and 5.29 s.

4 · Complex numbers & i (problems 8–9)

The one rule: i = √−1, so i² = −1. A complex number is written a + bi (real part first).

Add, subtract, multiply

  • Add/subtract: combine real with real, i with i. Distribute a minus sign to both parts.
  • Multiply: FOIL (or distribute), then replace every i² with −1 and combine.
Twin: (3 − 2i)(5 − 4i) = 15 − 12i − 10i + 8i² = 15 − 22i + 8(−1) = 7 − 22i.
Twin: 4i(2 − 3i) − (1 − 5i) = 8i − 12i² − 1 + 5i = 8i + 12 − 1 + 5i = 11 + 13i.
Trap: −12i² becomes +12 (minus times minus). And −(1 − 5i) = −1 + 5i.

Powers of i: they repeat every 4

i¹i²i³i⁴
i−1−i1

Divide the exponent by 4 and use the remainder: remainder 1 → i, 2 → −1, 3 → −i, 0 → 1.

Twins: i¹⁸: 18 ÷ 4 = 4 r 2 → −1.   i³¹: 31 ÷ 4 = 7 r 3 → −i.

Square roots of negatives

Pull out the i first: √−n = i√n. Then simplify the radical: look for the biggest perfect square that divides n.

Twins:
√−98 = i√98 = i√(49·2) = 7i√2
3√−48 = 3·i√(16·3) = 3·4i√3 = 12i√3
(3√−25)(√8) = (3·5i)(2√2) = 30i√2
√49 + √−16 − √25 − √−1 = 7 + 4i − 5 − i = 2 + 3i
Trap: write the i outside the radical (7i√2, not 7√2i), so it can't be misread as being under the root.

Solve by factoring: x² − 5x − 24 = 0

Show answer
Multiply to −24, add to −5: −8 and +3. (x − 8)(x + 3) = 0 → x = 8 or x = −3.

Solve by factoring: 4x² + 4x − 15 = 0

Show answer
ac = −60; multiply to −60, add to 4: +10 and −6. 4x² + 10x − 6x − 15 = 2x(2x + 5) − 3(2x + 5) = (2x − 3)(2x + 5) → x = 3/2 or x = −5/2.

Show answer

Show answer

For f(x) = (x − 2)(x + 4), find the x-intercepts, axis of symmetry, vertex, y-intercept, standard form and vertex form.

Show answer
x-intercepts (2, 0), (−4, 0) · axis halfway: (2 + −4)/2 = x = −1 · vertex f(−1) = (−3)(3) = −9 → (−1, −9) · y-intercept f(0) = (−2)(4) → (0, −8) · standard x² + 2x − 8 · vertex form (x + 1)² − 9.
9

Convert y = 2(x − 1)² − 18 to standard form, then to intercept form.

Show answer
Standard: 2(x² − 2x + 1) − 18 = 2x² − 4x + 2 − 18 = 2x² − 4x − 16. Intercept: take out the 2: 2(x² − 2x − 8) = 2(x − 4)(x + 2).
10

A parabola has its vertex at (3, −2) and crosses the y-axis at (0, 16). Write it in all three forms.

Show answer
Vertex form starts y = a(x − 3)² − 2. Plug in (0, 16): 16 = 9a − 2 → a = 2.
Vertex: y = 2(x − 3)² − 2 · Standard: 2(x² − 6x + 9) − 2 = 2x² − 12x + 16 · Intercept: 2(x² − 6x + 8) = 2(x − 2)(x − 4).
11

A rock is launched from a platform: y = −16x² + 80x + 96. (a) Initial height? (b) Max height? (c) When does it hit the ground? (d) When is it 150 ft up? Round to the hundredth.

Show answer
(a) 96 ft. (b) x = −80/(−32) = 2.5 s; y = −16(6.25) + 80(2.5) + 96 = −100 + 200 + 96 = 196 ft. (c) ÷ −16: x² − 5x − 6 = 0 → (x − 6)(x + 1) = 0 → 6 s. (d) −16x² + 80x − 54 = 0 → formula: x = (−80 ± √2944)/(−32), √2944 ≈ 54.26 → x ≈ 0.80 s and 4.20 s.
12

Simplify: (a) (2 + i)(3 − 4i)  (b) 2i(4 + i) − (6 − 2i)  (c) (4 + 2i) − 3i(2 − 5i)  (d) i²²  (e) i⁴¹

Show answer
(a) 6 − 8i + 3i − 4i² = 10 − 5i. (b) 8i + 2i² − 6 + 2i = 8i − 2 − 6 + 2i = −8 + 10i. (c) 4 + 2i − 6i + 15i² = 4 + 2i − 6i − 15 = −11 − 4i. (d) remainder 2 → −1. (e) remainder 1 → i.

Show answer
