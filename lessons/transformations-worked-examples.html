Twin 1 · Quadratic

g(x) = −2(x − 1)² + 3

A stand-in — not one of your eight. Watch the method.

  1. Parent: there's an x² → quadratic.
  2. Knobs: a = −2, h = 1 (the −1 flips to right 1), k = 3.
  3. Transformations: stretch ×2, reflected (a<0 → opens down), right 1, up 3.
  4. Vertex: (h, k) = (1, 3).
  5. Domain: parabola → (−∞, ∞).
  6. Range: opens down from 3 → (−∞, 3].
  7. y-int: −2(0−1)² + 3 = −2(1) + 3 = 1.
  8. Graph: plot (1, 3); from the vertex the stretch gives the next points — right 1 / down 2, right 2 / down 8 (that's a·1² and a·2²). Mirror on the left.
Twin 2 · Absolute value

g(x) = |x + 2| − 1

  1. Parent: |x| → absolute value (V-shape).
  2. Knobs: a = 1, h = −2 (left 2), k = −1 (down 1).
  3. Transformations: left 2, down 1 (a = 1, so no stretch or flip).
  4. Vertex: (−2, −1).
  5. Domain: (−∞, ∞).
  6. Range: a>0 → V opens up → [−1, ∞).
  7. y-int: |0 + 2| − 1 = 2 − 1 = 1.
  8. Graph: plot (−2, −1); the arms go up 1 / right 1 and up 1 / left 1 (slope ±1).
Twin 3 · Square root

g(x) = √(x − 2) + 1

  1. Parent: √x → square root (half-curve).
  2. Knobs: a = 1, h = 2 (right 2), k = 1 (up 1).
  3. Transformations: right 2, up 1.
  4. Start point: (2, 1).
  5. Domain: [2, ∞) — the inside x − 2 can't be negative, so x starts at 2.
  6. Range: a>0 → [1, ∞).
  7. y-int: none — x = 0 isn't allowed (the curve starts at x = 2).
  8. Graph: start at (2, 1); the curve rises to the right, flattening as it goes.
Twin 4 · Linear

g(x) = 2x − 5

  1. Parent: x → line.
  2. Read it: slope 2, y-int −5. No vertex.
  3. Domain & Range: both (−∞, ∞).
  4. Graph: from (0, −5) go up 2 / right 1, repeat.
