Steps shown, not just the final number — so you can see where a slip happened.

Do the practice first. Checking before you've tried is how the method never sticks. Once you've worked them, reveal and compare step by step.

A · g(x) = x2 − 3x + 4

g(0) = 0 − 0 + 4 = 4 g(2) = (2)2 = 4; 4 − 6 + 4 = 2 g(−1) = (−1)2 = 1; 1 + 3 + 4 = 8 g(5) = (5)2 = 25; 25 − 15 + 4 = 14

B · h(x) = −2x2 + 5x − 1

h(1) = −2(1) + 5 − 1 = 2 h(−2) = −2(−2)2 + 5(−2) − 1 = −8 − 10 − 1 = −19 h(3) = −2(9) + 15 − 1 = −18 + 15 − 1 = −4
Sign check: in h(−2), the input is squared inside its parentheses first — (−2)2 = 4, then −2 × 4 = −8. Miss the parentheses and this one goes wrong.

C · Solve for the input

1. 4x + 7 = 31 → 4x = 24 → x = 6 2. 6x − 5 = 43 → 6x = 48 → x = 8 3. −3x + 2 = 20 → −3x = 18 → x = −6

D · Solve the equations

1. 24 = 4(x − 3) + 8 → 24 = 4x − 12 + 8 → 24 = 4x − 4 → 28 = 4x → x = 7 2. 5n − 8n + 6 = −9 → −3n + 6 = −9 → −3n = −15 → n = 5 3. 2(3x − 1) = 28 → 6x − 2 = 28 → 6x = 30 → x = 5

E · Is it a function?

Yes — each input appears once. Domain = {1, 2, 3}. Range = {4, 7}.
4 is listed once in the range even though two inputs map to it — that's allowed. Two inputs sharing one output is fine; one input with two outputs is not.
