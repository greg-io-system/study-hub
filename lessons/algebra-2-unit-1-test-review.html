Half 1 · Functions (you've got lessons for this)

Three skills, all in the lessons you've already used — open them if any feel shaky:

The Function Machine (notation, domain & range) Transformations Explorer

Quick reminders

  • Evaluate f(number): plug the number in for x. Twin example — f(4) for f(x)=(x+2)²−5 → (4+2)²−5 = 36−5 = 31. (Watch the parentheses — square the whole thing.)
  • Solve for x (given the output): set the rule equal to the value and undo. Twin example — h(x)=−5x+9, solve h(x)=24 → −5x+9=24 → −5x=15 → x=−3.
  • Read a graph: f(10) = the y-value at x=10; "find x when f(x)=90" = the x where the height is 90. Domain = the x-values covered; range = the y-values reached. Say each in a sentence about the situation.
  • Transformations: in a·f(x−h)+k, h shifts left/right (opposite sign), k shifts up/down, a stretches/flips. Plot ≥5 points, then read domain & range off your graph. The sheet has three shapes: a parabola, an absolute value, and a square root.
  • Square roots are the sneaky one a√(x−h)+k: the graph starts at the corner point (h, k) and only goes one way (you can't square-root a negative), so unlike the parabola/abs its domain is not all reals — it's x ≥ h. Range starts at k. Twin example: y=√(x−3)+1 starts at (3, 1) → domain x ≥ 3, range y ≥ 1. (Watch the sign: √(x+9) means h=−9, so it starts at x=−9.)

Half 2 · Sequences (the part with no lesson yet)

A sequence is an ordered list of numbers (terms): a₁, a₂, a₃, … The subscript is the term number n. Everything on the test comes down to one question first:

Step 1 — Arithmetic or geometric? (add or multiply?)

Arithmetic = you ADD
Same number added each step. That number is the common difference d.
3, 7, 11, 15, … → +4 each time, d = 4.
Check: subtract neighbors. 7−3=4, 11−7=4. Same → arithmetic.
Geometric = you MULTIPLY
Same number multiplied each step. That number is the common ratio r.
2, 6, 18, 54, … → ×3 each time, r = 3.
Check: divide neighbors. 6÷2=3, 18÷6=3. Same → geometric.

If neither adding nor multiplying by a fixed number works, it's neither. (A decreasing one still counts: −3 each step is arithmetic with d=−3; ×¾ each step is geometric with r=¾.)

Step 2 — The explicit formula (jump straight to any term)

An explicit formula gives aₙ from n directly — no counting up. Memorize these two:

Arithmetic:   aₙ = a₁ + (n − 1)·d
Geometric:   aₙ = a₁ · r(n − 1)
Worked (arithmetic): 3, 7, 11, 15… has a₁=3, d=4, so aₙ = 3 + (n−1)·4 = 4n − 1. Check the 10th term: a₁₀ = 4(10)−1 = 39.
Worked (geometric): 2, 6, 18, 54… has a₁=2, r=3, so aₙ = 2·3(n−1). Check the 5th term: a₅ = 2·3⁴ = 2·81 = 162.

"Fully simplify" (like the test asks) means clean up the arithmetic one: 3+(n−1)·4 → 3+4n−4 → 4n−1.

Try it — build a sequence

Notice the points are dots, not a line — n only takes whole numbers (1, 2, 3…). There is no a₂.₅.

Step 3 — Word problems (the 4-step move)

Tables, cups, seats, populations — all the same four steps:

  1. Make a table of n (1, 2, 3…) and aₙ. Fill in what the story gives you.
  2. Add or multiply? Find d (arithmetic) or r (geometric) between terms.
  3. Write the explicit rule with the right formula, and simplify.
  4. Use it — plug in the n they ask for.
Parallel example: A plumber charges a $50 call-out, then $40 per hour. Cost after n hours: table 90, 130, 170… (n=1,2,3). Adds $40 → arithmetic, a₁=90, d=40. Rule: aₙ = 90 + (n−1)·40 = 40n + 50. After 6 hours: 40(6)+50 = $290.
Why a₂.₅ makes no sense: n counts whole hours/tables/cups — you can't have table number 3.2. The domain is whole numbers, so only dot-points exist.

Self-check (parallel problems — answer first, then reveal)

These mirror the test's problem types with different numbers, so your real review sheet stays yours.

1

Classify, then write the explicit formula: 5, 8, 11, 14, … and find the 20th term.

Show answer

Arithmetic (+3), a₁=5, d=3. aₙ = 5+(n−1)·3 = 3n+2. 20th: 3(20)+2 = 62.

2

Classify, then write the explicit formula: 4, 12, 36, 108, … and find the 6th term.

Show answer

Geometric (×3), a₁=4, r=3. aₙ = 4·3(n−1). 6th: 4·3⁵ = 4·243 = 972.

3

A sequence starts at 100 and drops by ¼ of the current value each week (100, 75, …). Arithmetic or geometric? Write the formula.

Show answer

Dropping by ¼ means keeping ¾ — you multiply by 0.75, so geometric, a₁=100, r=¾. aₙ = 100·(0.75)(n−1). (If the story said "drops by 25 each week," that fixed subtraction would be arithmetic instead.)

4

Evaluate for f(x)=(x+2)²−4: find f(1). Then solve f(x)=−4.

Show answer

f(1)=(1+2)²−4 = 9−4 = 5. Solve (x+2)²−4=−4 → (x+2)²=0 → x=−2.

5

Chairs around square tables in a row: 1 table seats 4, each added table adds 2 seats (4, 6, 8…). Write the rule and find seats at 12 tables. Why doesn't a₂.₅ make sense?

Show answer

Arithmetic, a₁=4, d=2. aₙ = 4+(n−1)·2 = 2n+2. 12 tables: 2(12)+2 = 26 seats. a₂.₅: n counts whole tables — there's no "2.5 tables," so only whole-number terms exist (dots, not a line).

6

From a graph, f(8)=120 and the curve covers x from 0 to 30 reaching y from 60 to 150. State f(8) in a sentence, and the domain and range.

Show answer

f(8)=120: "At 8 minutes, the value was 120." Domain: 0 ≤ x ≤ 30 (the times shown). Range: 60 ≤ y ≤ 150 (the values reached). Always tie it back to what x and y mean in the story.

7

Graph h(x)=√(x+4)−2: where does it start, and what are the domain and range?

Show answer

√(x+4) means h=−4, so it starts at (−4, −2) and goes right/up only. Domain: x ≥ −4. Range: y ≥ −2. Plot from x=−4: (−4,−2), (−3,−1), (0,0), (5,1)…
