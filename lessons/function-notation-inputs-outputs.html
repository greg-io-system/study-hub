The Input → Output Machine

Every function is a little machine: you drop a number in, it does its job, a number comes out. Get that one picture and the whole worksheet is the same idea, over and over.

Start here

What f(3) is really saying

The notation looks like multiplication, but it isn’t. Read it out loud like this:

f ( 3 )  =  ?

f

the name of the machine (just a label, like a nickname).

3

the input — the number you drop in.

?

the output — the number that comes out. That’s what you’re finding.

Say it this way: “f of 3” means “put 3 into machine f — what comes out?” It is not “f times 3.”
The big one

One function, four ways to see it

This is the part that makes everything click. The same function can be shown as a rule, a table, a graph, or a mapping — they all say the identical thing. Here it’s f(x) = 2x + 1. Pick an input and watch it light up in all four at once.

Why this matters: on the worksheet, some problems give you a graph, some give a rule, some give a mapping. They’re not different skills — they’re the same machine wearing different clothes.
Skill 1

Given the input → find the output

This is Problem 3 on her sheet: f(x) = -2x² - 4x + 5. The trick that prevents 90% of mistakes: put the input in parentheses, then do it in order. Drag the input and watch every step.

3
Now you try, on paper: this same function at f(0) and f(7). Slide to check yourself after.
Sign trap: a negative input must be squared with its parentheses. (-3)² = 9, but -3² = -9. The parentheses are what keep you safe.
Skill 2

Reading a value off a graph

Problems 1 and 2 give you a graph instead of a rule. Same machine. To find f(x): start at the input on the bottom, go up to the curve, then across to read the output. Drag the dot.

Backwards version (Problem 1B, “when is f(x)=3?”): start at 3 on the side, go across to the curve, then down to the input. There can be more than one answer — find them all.
Skill 3

Given the output → find the input

The other half of Problem 3: you’re told what came out, and you find what went in. Run the machine in reverse — set the rule equal to the output and peel the operations off, last one first.

Forward (Skill 1)

input 5 →
6(5) + 12
= 30 + 12
= 42 output

Backward (Skill 3)

output 42:
6x + 12 = 42
6x = 30  (undo +12)
x = 5  (undo ×6)

Your turn: n(x) = 6x + 12, n(x) = 42 and n(x) = 8x - 3, n(x) = 45. Check by plugging your answer back in — it should give the target output.
Skill 4

Domain, range & “is it a function?”

Domain = all the inputs (x, read left–right). Range = all the outputs (y, read bottom–top).

A relation is a function only if every input has exactly one output. Test it with a vertical line: slide it across — if it ever touches the graph twice at once, it fails. Drag the line on both.

A parabola

A sideways parabola

On a mapping diagram (the ovals with arrows in Problem 4): same rule. If any single input arrow splits to two outputs, it’s not a function. Two inputs sharing one output is fine.

The whole sheet in one sentence: ask “what’s the input, what’s the output, and which one am I given?”
