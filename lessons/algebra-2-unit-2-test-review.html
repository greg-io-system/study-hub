Part 1 · Systems refresher (you have a lesson for this)

Systems of Two Equations (interactive lesson)

Is the point a solution? Check BOTH equations

A point solves a system only if it works in every equation. One out of two is a "no."

Twin: is (2, −1) a solution of y = 3x − 7 and x + y = 1?
First: −1 = 3(2) − 7 = −1 ✓.  Second: 2 + (−1) = 1 ✓. Both work → yes.
Twin with a square: is (−1, 3) a solution of y = x + 4 and y = x² + 1?
First: 3 = −1 + 4 ✓.  Second: (−1)² + 1 = 2, not 3 ✗ → no. (Square the negative in parentheses: (−1)² = +1.)

When the variables disappear

Sometimes substitution or elimination wipes out both variables. Read what's left:

True statement (like 5 = 5)
Same line twice → infinitely many solutions.
Twin: y = 2x − 1, 4x − 2y = 2 → 4x − 2(2x − 1) = 2 → 2 = 2.
False statement (like 8 = 5)
Parallel lines → no solution.
Twin: y = −3x + 4, 6x + 2y = 5 → 6x − 6x + 8 = 5 → 8 = 5.

Shortcut: before solving, check whether one equation is just the other multiplied by a number. If the WHOLE equation matches, it's infinitely many. If the left sides match but the right sides don't, it's no solution.

Elimination: multiply so one variable cancels

Twin: 2x + 3y = 12 and 5x − 6y = 3.
The y's are 3 and −6, so multiply the first equation by 2 (every term, both sides): 4x + 6y = 24.
Add: 9x = 27 → x = 3. Back into the first: 6 + 3y = 12 → y = 2.
Check in the other equation: 5(3) − 6(2) = 3 ✓. Answer (3, 2).

Graphing two lines: get both into y = mx + b first

A standard-form equation like 4x − 2y = 6 hides its slope. Solve for y: −2y = −4x + 6 → y = 2x − 3. Paired with y = 2x + 1: same slope, different y-intercept → parallel, no solution. You can say that without drawing anything.

Part 2 · A line crossing a parabola

A line can cross a parabola in two places, touch it in one, or miss it entirely (none). So a parabola-and-line system can have two answers. Write down both.

Parabola  y = (x − h)² + k
Line  y = mx + b

Try sliding b down until the line just touches the parabola (one solution), then further until it misses (no solution).

Solving it by algebra (the way to check your graph)

  1. Set them equal, since both equal y: (x − 2)² = x + 4.
  2. Expand and move everything to one side: x² − 4x + 4 = x + 4 → x² − 5x = 0.
  3. Factor and solve: x(x − 5) = 0 → x = 0 or x = 5.
  4. Get each y from the LINE (easier): y = 0 + 4 = 4 and y = 5 + 4 = 9. Solutions (0, 4) and (5, 9).
Common slip: (x − 2)² is NOT x² − 4. Write it as (x − 2)(x − 2) and multiply it out: x² − 4x + 4. On a graphing problem, plot the vertex (h, k) and two points on each side, then read off where the line crosses.

Part 3 · Word problems: write the system yourself

  1. Define two variables in words: "c = people in each car, v = people in each van."
  2. One equation per fact. The story gives two separate facts, so you get two equations.
  3. Solve with substitution or elimination, whichever is quicker.
  4. Answer the question in a sentence, with units, and check it against the story.
Twin (vehicles): One group fills 3 cars and 2 vans with 26 people. Another fills 5 cars and 4 vans with 48 people. Every car holds the same number, and so does every van.
c = people per car, v = people per van.  3c + 2v = 26,  5c + 4v = 48.
Double the first: 6c + 4v = 52. Subtract the second: c = 4. Then 12 + 2v = 26 → v = 7.
Answer: 4 people per car, 7 per van. Check the second group: 5(4) + 4(7) = 48 ✓

The current problem (the one that trips people up)

Going with the current, the speeds add. Going against it, they subtract. Speed = distance ÷ time.

Twin (kayak): A kayak goes 36 miles downstream in 3 hours and takes 9 hours to come back.
k = kayak speed in still water, c = current speed.
Downstream: k + c = 36 ÷ 3 = 12.  Upstream: k − c = 36 ÷ 9 = 4.
Add the two: 2k = 16 → k = 8, so c = 4.
Answer: the kayak goes 8 mph in still water, and the current is 4 mph.

Count-and-weight problems (candy, coins, marbles) follow the same pattern: one equation counts the items, the other adds up their weight or value. Ticket problems: one equation per day of sales.

Part 4 · Piecewise functions (new: no lesson yet)

A piecewise function uses different rules for different x-values. A phone plan works like this: one price up to your data limit, a different price after it. It's written with a big brace. Each line is a rule, and the condition beside it says when that rule applies.

p(x) ={
x + 3if x < −2
x²if −2 ≤ x ≤ 3
10if x > 3

Evaluating: find the right rule FIRST

  1. Look only at the conditions. Which one does your x fit?
  2. Watch the edges: ≤ and ≥ include the number; < and > do not.
  3. Use that one rule and ignore the others.
p(−6): −6 < −2 → top rule → −6 + 3 = −3.
p(−2): not < −2, but it fits −2 ≤ x → middle rule → (−2)² = 4.
p(3): 3 ≤ 3 ✓ → middle → 9.   p(7): 7 > 3 → bottom → 10 (a constant rule: the answer is 10 whatever x is).

Graphing: each piece only over its own stretch

Draw each rule only where its condition is true. At the break point, the dot tells you whether that end is included:

● Closed (filled) dot
The condition uses ≤ or ≥. That point belongs to this piece.
○ Open (hollow) dot
The condition uses < or >. The piece runs right up to the point but doesn't include it.
Piece 1:  y = m₁x + b₁, to the LEFT of the break
Piece 2:  y = m₂x + b₂, to the RIGHT of the break

Slide "Evaluate at" onto the break point and flip the toggle. The same x switches to the other piece. Then try to make the two pieces meet with no jump.

Writing one from a story

Twin (gym): A gym charges $12 per visit for your first 5 visits in a month, then $8 per visit after that. Write the cost C(v) for v visits.
Up to 5 visits, it's just 12v. After that you've already paid 5 × 12 = $60, plus $8 for each visit beyond 5, which is (v − 5) visits:
C(v) ={
12vif 0 ≤ v ≤ 5
60 + 8(v − 5)if v > 5

9 visits: 60 + 8(4) = $92.  Check: both rules give $60 at v = 5, so the pieces meet. That's a good sign.
The big mistake: writing ONE formula, like 12v − 8v. A piecewise function exists because the rule changes at a certain point (here, visit 5). You need two lines with two conditions, and the second line has to include what was already paid in the first stretch.

Self-check (parallel problems: answer first, then reveal)

These match the test's problem types with different numbers, so your real sheets stay yours.

1

Is (1, 4) a solution of y = 2x + 2 and y = x² + 3?

Show answer

2(1) + 2 = 4 ✓ and 1² + 3 = 4 ✓. Both work → yes.

2

Substitution: x = 2y + 1 and 3x − 4y = 9.

Show answer

3(2y + 1) − 4y = 9 → 6y + 3 − 4y = 9 → 2y = 6 → y = 3; x = 2(3) + 1 = 7. Answer (7, 3).

3

Elimination: 3x + 2y = 7 and 6x + 4y = 10. How many solutions?

Show answer

Double the first: 6x + 4y = 14. Subtract the second: 0 = 4, which is false → no solution (parallel lines). The left sides match but the right sides don't.

4

Solve y = (x + 1)² and y = x + 3. (Then set them up in the explorer above to see it: h = −1, k = 0, m = 1, b = 3.)

Show answer

x² + 2x + 1 = x + 3 → x² + x − 2 = 0 → (x + 2)(x − 1) = 0 → x = −2 or 1. From the line: (−2, 1) and (1, 4). Two solutions.

5

A motorboat goes 60 miles downstream in 2 hours and back upstream in 3 hours. Find the boat's speed in still water and the current's speed.

Show answer

b + c = 60 ÷ 2 = 30, b − c = 60 ÷ 3 = 20. Add: 2b = 50 → boat 25 mph, current 5 mph.

6

A play sells 4 adult and 3 student tickets for $54, and 2 adult and 5 student tickets for $48. Find each price.

Show answer

4a + 3s = 54, 2a + 5s = 48. Double the second: 4a + 10s = 96; subtract the first: 7s = 42 → s = 6; then 4a + 18 = 54 → a = 9. Adult $9, student $6.

7

A jar has 30 marbles weighing 96 grams. Big marbles weigh 5 g and small ones 2 g. How many of each?

Show answer

B + S = 30, 5B + 2S = 96. Double the first: 2B + 2S = 60; subtract: 3B = 36 → 12 big, 18 small. Check: 60 + 36 = 96 ✓

8

Evaluate at x = −1 and x = 4:

r(x) ={
3xif x ≤ −1
5if −1 < x < 4
2x − 3if x ≥ 4
Show answer

r(−1): −1 ≤ −1 ✓ → top → 3(−1) = −3. (It isn't the middle rule, because that one needs −1 < x.)

r(4): 4 ≥ 4 ✓ → bottom → 2(4) − 3 = 5.

9

Graph s(x) = 5 if x < 2, and s(x) = x + 1 if x ≥ 2. Where are the open and closed dots? Is there a jump?

Show answer

Flat line at y = 5 coming from the left, ending in an open dot at (2, 5) (x < 2 doesn't include 2). The line y = x + 1 starts with a closed dot at (2, 3) and rises to the right. The y-values are different at x = 2 (5 vs 3), so yes, it jumps. (Check it in the builder: m₁=0, b₁=5, m₂=1, b₂=1, break at 2.)

10

Bike rental: $15 per hour for the first 3 hours, then $10 per hour after that. (a) Write C(h). (b) Cost for 5 hours? (c) How much more is 4 hours than 2 hours?

Show answer

(a) C(h) = 15h if 0 ≤ h ≤ 3; C(h) = 45 + 10(h − 3) if h > 3.

(b) 45 + 10(2) = $65.  (c) 4 hours: 45 + 10 = $55; 2 hours: 15(2) = $30. The difference is $25. (Each time, check which piece you're in first.)
